ASCII Art Video Player 📽️

Turn your frames into ASCII art!

About this Project 📄

This website is the web version of my Python ASCII art project. The original program used OpenCV to read a video, converted each frame to grayscale, and printed it in the terminal as text characters.

The dark pixels turn into light characters such as spaces, while the bright pixels turn into heavy characters like @. When the video is played fast, the screen seems to move like an animation made of characters.

This project was inspired by the Bad Apple!! music video, a popular meme that became a symbol of ASCII art videos. The original video is a black-and-white animation set to a song from the Touhou Project series.

How It Works ⚙️

  1. The video plays in the background.
  2. Each frame is drawn onto a small hidden canvas.
  3. Every pixel is turned into a brightness value from 0 to 255.
  4. The brightness picks a character from the selected character set.
  5. The characters are joined into text and shown in the player.

Features 🎨

  • Upload your own video file from your device
  • Play, pause, and reset controls
  • Four resolutions, from Low (60x) to Max (200x)
  • Three ASCII character sets: Complex, Classic, and Modern
  • Adjustable font size, playback speed, and volume
  • On mobile devices, the resolution starts at Low (60x) for best performance
