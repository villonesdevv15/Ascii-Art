## Features

* **Terminal ASCII Rendering:** Converts video frames to ASCII art in real-time using OpenCV.
* **Audio Synchronization:** Synchronizes video frames with audio playback using `pygame.mixer`.
* **Multiple Character Sets:** Supports various character ramps optimized for different videos (Original Bad Apple!!, SEKAI version, and Honeypie).
* **Smooth Frame Rate & Quality:** Synchronized timing loop prevents frame delays during terminal rendering.

# About this Project 📄
* This website is the web version of my Python ASCII art project. The original program used OpenCV to read a video, converted each frame to grayscale, and printed * it in the terminal as text characters.

* The dark pixels turn into light characters such as spaces, while the bright pixels turn into heavy characters like @. When the video is played fast, the screen * seems to move like an animation consisting of characters.

* This was inspired by the Bad Apple!!悪い リンゴ music video which is a popular meme and become the symbol of ASCII Arts. The original video is a black-and-white * animation of the song "Bad Apple!!悪い リンゴ" from the Touhou Project series.

# How It Works ⚙️
* The video will play in the background
* Each frame is drawn onto a small hidden canvas.
* Every pixel is turned into a brightness value from 0 to 255.
* The brightness picks a character from the selected character set.
## Features 🎨
* Upload your own video file from your device
* Press play, pause, and reset controls
* Has four resolutions, from Low (60x) to Max (200x)
* Have three ASCII character sets from Basic and Complex sets
* Has an adjustable font size and playback speed
* For Mobile Device set your resolution to Low (60x) for optimization
