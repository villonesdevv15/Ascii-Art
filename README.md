## Features

* **Terminal ASCII Rendering:** Converts video frames to ASCII art in real-time using OpenCV.
* **Audio Synchronization:** Synchronizes video frames with audio playback using `pygame.mixer`.
* **Multiple Character Sets:** Supports various character ramps optimized for different videos (Original Bad Apple!!, SEKAI version, and Honeypie).
* **Smooth Frame Rate & Quality:** Synchronized timing loop prevents frame delays during terminal rendering.
